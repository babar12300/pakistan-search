## Development

The project was created with Lovable. The root `README.md` describes local development with Node.js and npm:

```bash
git clone https://github.com/babar12300/pakistan-search.git
cd pakistan-search
npm install
npm run dev
```

Available package scripts also include:

- `npm run build` — build the application
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint
- `npm test` — run the test suite
